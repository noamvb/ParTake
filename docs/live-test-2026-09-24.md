**Conclusion: sliding window.** 5 segments dropped off the front and 5 were added at the end; count and length stayed the same. No
`EXT-X-PLAYLIST-TYPE`, no `EXT-X-ENDLIST`. A viewer can rewind **46,801 s ≈ 780 min ≈ 13 h**.

(14:08:25Z), so the full sitting is inside the window. To seek to the start of the sitting, the player needs
`position = STARTTIME − chunklist #STARTTIME`, not 0. At 780 min, a sitting that started 10:08 stays fully rewindable until about 23:00.
Segment file names are numbered one above MEDIA-SEQUENCE (seq 33217 → `_33218.ts`); this is harmless.
